## Goal
The web app consumes the backend through a **vendored, pinned** copy of `api/openapi.yaml` at tag `api-v0.1.0`, with generated
types, one typed client wrapper (`src/lib/api`) that builds `If-Match` and turns problem+json into `ApiError`, TanStack Query
wired app-wide, and MSW handlers built from the spec's examples, usable in tests **and** in the dev server without a backend.
After this PR no code calls `fetch` directly, and M2 web tasks (W-04+) can build features against mocks.

## Scope
1. **`scripts/api-sync.mjs` + `npm run api:sync -- api-v0.N.0`.** Plain Node, no new deps for the script itself.
   - Gets `api/openapi.yaml` at that **tag** from the backend repo. Default: shallow clone of
     `https://github.com/0xfederama/collections-app-backend.git` at the tag into a temp dir (works from any worktree; no `../`
     paths). Optional `--from <path-to-backend-checkout>` reads it with `git -C <path> show <tag>:api/openapi.yaml`.
   - Writes `api/openapi.yaml` and `api/openapi.lock.json` (`{ tag, commit, sha256 }`; Q-01 later checks out the backend at
     `commit`), then regenerates `src/generated/` (openapi-typescript) and the examples file (item 4). Refuses a non-tag ref.
2. **`npm run api:check`, added to `npm run check`.** Offline. Fails if the sha256 of `api/openapi.yaml` doesn't match the lock,
   or if regenerating into a temp dir differs from the committed `src/generated/`. Readable error saying to run `api:sync`.
   `src/generated/` is excluded from prettier and eslint, and committed.
3. **`src/lib/api/`** (openapi-fetch client, same-origin `baseUrl`, relative paths so the Vite proxy and Caddy just work).
   - `ApiError` with `status`, `code`, `title`, `detail`, `currentVersion?` (412), `requestId` (from `X-Request-Id`), and
     the raw problem. Non-problem error bodies still become an `ApiError` (code `unknown`).
   - A separate `NetworkError` (fetch threw, aborted excluded) so callers can tell "server said no" from "server unreachable".
   - `If-Match`: ETags are typed per resource (`"f-N"`, `"l-N"`, `"i-N"`, `"c-N"`, `"s-N"`, D-054 / API §3). Provide a typed
     helper so callers pass the resource and its `version`, never a hand-built string, and never `*`. Never auto-retry a 412.
   - Unit tests: problem parsing for 400/404/409/412/422/428, `currentVersion`, request id, network error, ETag builder.
4. **MSW (`src/mocks/`).**
   - Handlers for every operation, answering with the spec's example responses. Get the examples out of the YAML at **sync time**
     (into `src/generated/`), so the app never parses YAML at runtime. Prefer a YAML parser already in the dependency tree via
     openapi-typescript over adding one; if you must add one, justify it.
   - Keep handlers stateless for now (W-04+ may add in-memory state). Export them so tests can override per case.
   - Tests: Node server started in `src/test-setup.ts` with `onUnhandledRequest: 'error'`, reset between tests.
   - Dev: `VITE_API_MOCKS=1 npm run dev` starts the browser worker before rendering (lazy import, absent from the prod bundle;
     verify with `rg` on `dist`). Commit `public/mockServiceWorker.js` and document it. Default dev still uses the real proxy.
5. **TanStack Query.** `src/app/queryClient.ts` with conservative defaults (no retry on 4xx, at most 1 retry on network
   errors, sensible `staleTime`; record your choices in the PR). `QueryClientProvider` in `App.tsx`. Tests get a fresh client
   per render: extend `createTestRouter` or add a `renderWithProviders` helper. No devtools package.
6. **Replace `src/lib/backendStatus.ts`.** Delete it and add `src/features/health/api.ts` with a query hook on `/readyz`
   through the client. Update `AppShell.tsx` for that only (no layout change, that's W-04). Same three states as today.
7. **Docs.** CLAUDE.md: fill the `api:sync`/`api:check` row, remove the "until then only backendStatus.ts" line, add gotchas
   (mocks flag, `src/generated/` never edited, typed ETags). docs-keeper adds `docs/modules/api.md`.
