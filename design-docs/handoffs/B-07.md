## Scope
- **Kind registry** `internal/items/kinds`: one validator per kind (`generic`, `movie`, `tv_show`, `motorcycle`, `car`, `camera`) per
  DATA_MODEL §2.1: all keys optional, `null` → key omitted, text trimmed and ≤ 100 unless noted, ranges, enums, 1-decimal numbers,
  `imdb_url` pattern, `streaming` sub-shape (country required, ≤ 30 unique case-insensitive platforms ≤ 60 chars), cross-field rules
  (`end_year ≥ first_air_year`, `electric_range_km` only for electric/plugin_hybrid or absent fuel). Unknown key → 400 `unknown_field`
  (`metadata.<key>` path); wrong value → 422 with `metadata.<key>` field. Pure Go, unit-tested exhaustively (AT-05 U part).
- **Item fields**: title 1–300 trimmed, summary ≤ 1000, status ≤ 100, `official_website_url` http/https only (`javascript:` etc. → 422),
  ≤ 2048. **Price** (D-015): decimal strings `^\d{1,10}\.\d{2}$`, min ≤ max, currency `^[A-Z]{3}$` required when any price is set,
  stored as NUMERIC(12,2) (choose the Go mapping for `pgtype.Numeric` ↔ string and record it in DECISIONS, D-049 left this to you; no
  float conversions anywhere). `price: null` clears all three columns.
- **PATCH**: only supplied fields (`nullable.Nullable`: absent vs `null`); if `kind` changes and `metadata` is absent, metadata resets to
  `{}`; if both, validate metadata against the new kind. If-Match `"i-N"` → 412 with `current_version`; bump `version`, `updated_at`.
  No-op PATCH → 200, no bump (as D-059/D-060).
- **Create** under `POST /lists/{id}/items`: list must be active (else 404 per the spec), appended last, kind default `generic`,
  201 + `Location` + `ETag`.
- **Read model** shared by Item and ItemSummary: `image` from `image_url` / `image_attachment_id` + `attachments` (url, thumbnail_url,
  width, height, original_filename; build URLs as in API.md §2), `price`, `content_version` = `max(version)` of the item's content
  versions, 0 if none (D-052). Set every nullable field explicitly (CLAUDE.md gotcha). Items B-09 later writes will render without changes here.
- **List items**: `?sort=manual|title|updated` (default = the list's `sort_mode`; title = case-insensitive, updated = newest first),
  tie-breaker `id`; `?q=` case-insensitive title substring (uses the trigram index); `limit` default 50 max 200, `offset`; response
  `{ data: [ItemSummary], page: { limit, offset, total } }`. Trashed list → 404.
- **Move** `{ list_id }`: destination list active (else 409 `destination_unavailable`), appended last, bumps `version`.
- **Reorder** `PUT /lists/{id}/items/order`: all active items of the list, set equality (DATA_MODEL §7, AT-21 rules) → 409 `order_stale`,
  `sort_order = index`, no version bumps, 204, allowed regardless of `sort_mode`.
- Locking: take D-060's per-workspace tree lock for create/move/reorder (or justify a narrower one in DECISIONS).
- `getItem` returns `path` (folders and list). Trashed or missing item → 404.
