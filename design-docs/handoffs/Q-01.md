## Goal
`npm run e2e` brings up the backend at the exact commit the web app's contract is pinned to, serves the built web app against it,
seeds data through the API, and runs the browser acceptance tests. Local only (D-031, no CI), not part of `npm run check`.

## Scope (Q-01a)
1. **Backend at the pinned ref:** read `commit` from `api/openapi.lock.json`, get the backend at that commit in a temp dir or a
   cached checkout (clone over HTTPS like `api-sync.mjs`, or `--from <path>` for offline), `docker compose -p <isolated name> up
   --build -d` with host ports bound to **127.0.0.1** only and a dedicated volume, wait for `/readyz`, and `down -v` at the end
   (also on failure / Ctrl+C). Never reuse or wipe the developer's own compose project. If the backend compose can't be
   parameterized (fixed ports, names), report it to the orchestrator as a backend gap instead of patching the backend from here.
2. **Web under test:** `vite build` + `vite preview` with the `/api` and `/readyz` proxy pointed at the e2e backend (Playwright
   `webServer`); same-origin like prod. Confirm `preview` honors the proxy, else document the alternative.
3. **Seeding:** a small typed API helper over Playwright's `request` (use the generated types) to create folders/lists/items per
   test; each test seeds what it needs; reset between tests or use unique names (pick one, keep tests independent and parallel-safe).
4. **Specs** (`describe("AT-xx …")`): AT-03 (create nested, move list root→folder→root, reorder siblings, persists after reload),
   AT-09 (two browser contexts, A saves, B saves → banner, draft intact, Copy works incl. fallback, Reload asks), AT-11 (delete
   folder → gone from tree/list/search/404; older separately deleted item stays in Trash after restoring the folder; restore with
   trashed parent → Restore to…; restore to destination; purge), AT-12 (case-insensitive substring, `%`/`_` literal, path shown),
   AT-13 (three links, order, encoding, rel), AT-14 (375/768/1024/1440: navigation via drawer/rail/sidebar works; axe has 0
   serious/critical on every **current** route in light and dark), AT-22 (edit, click another list → dialog; cancel keeps, confirm
   discards).
5. **Browsers:** Chromium only for now (lean, D-034); record it as a D-entry so adding WebKit later is a conscious choice.
6. **Scripts and docs:** `npm run e2e` (full run), `npm run e2e:ui` or `-- --headed` documented, traces/screenshots on failure in a
   gitignored folder. CLAUDE.md: the E2E row in the commands table, prerequisites (Docker), isolation notes. docs-keeper adds
   `docs/modules/e2e.md`.
