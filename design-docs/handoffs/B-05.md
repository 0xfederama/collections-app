## Scope
- **Bootstrap** (`internal/workspace`): one tx with `pg_advisory_xact_lock(<fixed constant>)`; if no workspace, insert it (name from
  `WORKSPACE_NAME`) and its settings row; if more than one exists, fail startup loudly. Called from `cmd/api` before the server starts; the
  ID goes into `httpapi.Deps.WorkspaceID` (`uuid.UUID`).
- **Settings service**: get, and patch of `workspace_name`, `streaming_country_code`, `default_currency`, `markdown_history_limit`
  (PATCH semantics: only supplied fields; `nullable.Nullable` gotcha in CLAUDE.md). One ETag stream `"s-N"` = `workspace_settings.version`,
  bumped by **any** change incl. the workspace name (API.md §3); the name lives in `workspaces.name`, updated in the same tx. Compare the
  If-Match version under a row lock (`FOR UPDATE`) or with `UPDATE … WHERE version = $n` → 412 `version_conflict` with `current_version`.
  Field rules → 422 `validation_failed` with per-field errors (name 1–200 trimmed, country `^[A-Z]{2}$`, currency `^[A-Z]{3}$`, limit 0–200).
  A PATCH that changes nothing: return 200 with the current version, no bump (say so in the PR).
- Queries in `db/queries/workspace.sql` (every query filters by `workspace_id`; sqlc regenerated and committed).
- Handlers: move `GetSettings` / `UpdateSettings` out of `unimplemented.go` into `settings.go`; set `ETag` on both responses.

## Tests
