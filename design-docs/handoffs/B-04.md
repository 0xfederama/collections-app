## Scope
**Database**
- `database.InTx(ctx, pool, func(q *sqlc.Queries) error) error`: commit on nil, rollback on error **and** on panic (re-panic after).
  Integration tests on testcontainers (commit, rollback, panic), plus a `NewPool` test (STATUS orchestrator notes).

**Domain errors** (`internal/apperr`, no HTTP imports)
- Typed errors the services will return: `NotFound`, `VersionConflict{Current int}`, `Validation{Errors []FieldError}`,
  `Conflict{Code, …}` for `cycle_detected`, `parent_in_trash` (with `blocking_parent`), `destination_unavailable`, `order_stale`,
  `PayloadTooLarge`, `UnsupportedMediaType`, `NotImplemented`. Keep it small; B-05+ extend it. Constructors + `errors.As` friendly.

**httpapi**
- `problem.go`: one writer for `application/problem+json` (API.md §4 shape, `type` URL per code, `request_id` on 500) and **one mapper**
  `apperr → status + code + extras`. Unknown errors → 500 `internal`, logged with the request id, never leaking SQL/paths/stacks.
- Mount the generated strict server on the chi router with `oapi.NewStrictHandlerWithOptions` + `oapi.HandlerWithOptions`:
  - `RequestErrorHandlerFunc` → 400 `malformed_request`; `ResponseErrorHandlerFunc` → the mapper (so handlers may just `return nil, err`
    with a domain error; typed problem responses stay allowed); `ChiServerOptions.ErrorHandlerFunc` → 400 `invalid_parameter`.
  - chi `NotFound` / `MethodNotAllowed` → problem+json 404 `not_found` / 405.
- **Stub server**: `Server` struct implementing `oapi.StrictServerInterface`. Put **every** operation in `unimplemented.go`, each returning
  `apperr.NotImplemented` → 501 problem. Endpoint tasks move their methods out into their own file (`settings.go`, `folders.go`, …), which
  keeps parallel PRs from colliding. Health operations: implement for real, keeping today's behavior and the `healthcheck` subcommand.
- **If-Match** (strict middleware keyed by `operationID`, list = API.md §3 "Requires If-Match"): missing, `*`, or not parseable as
  `"<prefix>-<N>"` with the operation's prefix → 428 `precondition_required`. Helper for handlers: `ifmatch.Version(params) int`, and
  `etag.Format(prefix, version)`. Record the "malformed = missing" rule as a DECISIONS entry.
- **Unknown fields** → 400 `unknown_field` (with the field path in `detail` or an extension). Recommended: one middleware driven by the
  embedded spec (kin-openapi route lookup; check only for properties the operation's request schema doesn't declare, recursively for
  nested objects; free-form `metadata` is left to B-07). Other schema rules stay in Go (422). If this proves awkward, fall back to
  `DisallowUnknownFields` decoding per operation and say why. Record the choice as a DECISIONS entry.
- **Body limits** (API.md §6) via `http.MaxBytesReader`: 64 KiB default JSON, 2 MiB `PUT …/content`, 10 MiB + 64 KiB multipart image
  `PUT` → 413 `payload_too_large`. Review the server `ReadTimeout`/`WriteTimeout` for the 10 MiB upload and note the result.
- Middleware order and content: request id (`X-Request-Id` on **every** response incl. 404/405/413/500; accept an incoming one only if it
  is a short safe token, else generate), structured slog access log (method, route pattern, status, duration, request id; no bodies, no
  query strings with user text), panic recovery → 500 problem, security headers (`X-Content-Type-Options: nosniff`,
  `Referrer-Policy: no-referrer`, `X-Frame-Options: DENY`, `Content-Security-Policy: default-src 'none'; frame-ancestors 'none'` on API
  responses). No CORS (D-033).
- `Clock` interface (ARCHITECTURE §2 Rules) injected through the router deps; real one in `cmd/api`.

**Tests** (table-driven, testcontainers where the DB is needed)
- **AT-10**: every operation in API.md §3's If-Match list returns 428 without the header and with `If-Match: *` (table generated from
  that list; with a valid header the stub answers 501).
- Mapper: each `apperr` → expected status, `code`, extras (`current_version`, `errors[]`, `blocking_parent`), content type.
- Unknown field (top level and nested, e.g. `price.foo`, `destination.bar`) → 400 `unknown_field`; malformed JSON → 400 `malformed_request`;
  bad query param (`limit=500`, `limit=abc`) → 400 `invalid_parameter`; over-limit body → 413 for each of the three limits.
- `X-Request-Id` and security headers present on 2xx, 404, 405, 413, 500 (a panicking test handler), and no internal detail in the 500 body.
- `InTx` and `NewPool` as above.

the nullable gotcha from B-03), docs-keeper for `docs/modules/httpapi.md` and `database.md`.
