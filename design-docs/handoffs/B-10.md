## Scope
- Service `internal/trash`, queries `db/queries/trash.sql`.
- **Delete** (folder `"f-N"`, list `"l-N"`, item `"i-N"`; 412 on mismatch): in one tx with the tree lock: lock R, must be active (404),
  insert the batch (`root_type`, `root_id`, `root_name`, `former_path` from active ancestors), mark R **and all currently active
  descendants** with `deleted_at` + `trash_batch_id` (recursive CTE: folders, then lists in them, then items in those lists). Already-
  trashed descendants keep their older batch. 204.
- **List trash**: `{ data: [TrashEntry], page }` newest first; `counts` (folders, lists, items in **this** batch), `former_path`,
  `restorable_in_place` (false when the original parent is trashed or gone). Paginate per the spec.
- **Restore** (no If-Match, tree lock): root's parent active → restore in place; else without `destination` → 409 `parent_in_trash` with
  `blocking_parent {type,id,name}` (the nearest trashed or missing ancestor); with `destination` (`{folder_id}` for folders/lists,
  `{list_id}` for items, D-054) validate like a move (active, cycle check for folders → 409) and re-parent. Clear `deleted_at` /
  `trash_batch_id` on every row of batch B, append the root last among its siblings, bump the root's `version`, delete row B.
  Returns `{ root_type, root_id }`. Unknown batch → 404.
- **Purge** (no If-Match): collect attachment IDs + storage keys of **all** items in the root's subtree (any batch); hard-delete the root
  (FK cascades remove descendants and content versions); delete the collected `attachments` rows; delete batch B and any other batch whose
  root no longer exists (nested older batches); commit; **then** delete files via the FileStore (log failures, the B-09 sweeper retries).
  204. Make sure no step deletes a batch row still referenced (D-051 fails loudly by design).
- Folder/list/item reads, tree, list items and search already filter `deleted_at IS NULL`; verify trashed resources now answer 404
  everywhere and disappear from tree/lists/search.
