## Goal
The web app has a complete, themed design system: semantic tokens for light and dark, a no-flash theme bootstrap, self-hosted
fonts, a favicon, and all 18 UI_SPEC §11 primitives in `src/components/ui/`, each with every state and a test. A dev-only
`/dev/ui` gallery shows them all. Later tasks (W-04+) only compose these primitives and never use raw colors.

## Scope
1. **Tokens** in `src/styles/tokens.css`.
   - Private palette vars (`--stone-50`…, `--teal-…`). Semantic tokens per theme under `:root, [data-theme=light]` and
     `[data-theme=dark]`: `--bg`, `--surface`, `--surface-raised`, `--border`, `--border-strong`, `--text`, `--text-muted`,
     `--accent`, `--accent-hover`, `--accent-fg` (text on accent), `--accent-text` (links, focus), `--focus-ring`,
     `--success|warning|danger-{bg,border,text}`. Also `--shadow-sm|md|lg` (dark leans on borders and raised surfaces),
     `--radius-sm|md|lg|xl` (6/10/16/24) and motion durations (150–200ms) plus easing. Values from UI_SPEC §11.
   - In `global.css`, map them with `@theme inline` (colors, radii, font families, type scale 0.75–2.5rem). Drop the default
     palette with `--color-*: initial` so raw colors can't be used; keep the 4px spacing base.
   - `dark:` custom variant on `[data-theme=dark]`; `color-scheme: light|dark` per theme (restores what M0 removed); body
     bg/text from tokens; a `prefers-reduced-motion` block that zeroes transition and animation durations.
2. **No-flash theme bootstrap.**
   - Inline `<script>` in the `index.html` head: read `localStorage['collection:theme']` (`system|light|dark`, in try/catch),
     fall back to `matchMedia('(prefers-color-scheme: dark)')`, set `document.documentElement.dataset.theme` before paint.
   - `src/lib/theme.ts`: `getThemePreference`, `setThemePreference(pref)` (persist and apply), `resolveTheme`, and a
     `useThemePreference()` hook that follows `matchMedia` changes in `system` mode. One shared storage-key constant,
     with a comment pointing at the inline script.
   - Note for Q-03: the inline script needs a CSP hash in the Caddyfile (add to CLAUDE.md gotchas).
3. **Fonts.** Install `@fontsource-variable/inter` and `@fontsource-variable/fraunces`; import once in `main.tsx`. Use the
   Fraunces entry with `opsz`/`SOFT` axes if Fontsource ships it (researcher verifies). Inter gets
   `font-feature-settings: "cv11","ss01"`; prices use `tabular-nums`. No CDN.
4. **Favicon.** `public/favicon.svg` (collection glyph in accent teal, internal `prefers-color-scheme` query),
   `<link rel="icon" type="image/svg+xml">`, and light/dark `<meta name="theme-color">`.
5. **Radix, per primitive (D-038).** Install only what is used and justify each in the PR: `react-dialog` (Dialog, Drawer),
   `react-alert-dialog`, `react-dropdown-menu` (Menu), `react-tooltip`, `react-toast`, `react-select`, `react-popover`
   (Combobox). `react-toggle-group` only if a native radio group can't give SegmentedControl correct semantics; record why.
   No `radix-ui` umbrella package and no `@radix-ui/themes`.
6. **Primitives** in `src/components/ui/`, one file each plus a test, and an `index.ts` barrel.
   - Button (primary/secondary/ghost/danger × sm/md; `pending` shows a spinner, sets `aria-busy`, disables), IconButton
     (TS-required `aria-label`, ≥44px target), TextField and TextArea (label, hint, error with
     `aria-invalid`/`aria-describedby`, prefix/suffix slot for units), Select, Combobox (filterable, keyboard, empty message),
     SegmentedControl, Menu, Dialog, AlertDialog (destructive confirm), Drawer (slides in, honors reduced motion), Tooltip,
     Toast (provider + `useToast()`, live region, success/error/info), Chip (text always shown, never color alone), Badge
     (kind icon), Card (hover lift), Skeleton, EmptyState (icon, Fraunces heading, sentence, action slot), Breadcrumbs
     (`nav` with `aria-label`, `aria-current`), Tree (ARIA tree: roving tabindex, arrows/Home/End/expand-collapse,
     `aria-expanded|level|selected`, controlled `expanded` and `selected`, render-prop rows; no data, no dnd).
   - Every interactive primitive covers hover, `:focus-visible` (2px accent ring, 2px offset), active, disabled, and
     destructive where it applies. Semantic tokens only.
   - `src/components/ui/icons.ts` is the only Lucide import site and holds the kind-icon map: generic=tag, movie=film,
     tv_show=tv, motorcycle, car, camera (D-047).
7. **`/dev/ui` gallery.** Registered only when `import.meta.env.DEV`, through route `lazy`, so it is absent from the prod
   bundle. Shows every primitive in every state, a System/Light/Dark switcher (`setThemePreference`), and section anchors.
   Inside or outside AppShell is the worker's choice; record it under Progress.
8. **Placeholders.** In `AppShell.tsx`, `HomeRoute.tsx`, `NotFoundRoute.tsx` change className strings only, to token classes
   (the `stone-*` classes disappear with the default palette). No structural change (W-04).
9. **Tests** (test-writer writes them; you run and review them).
   - Per-primitive role, keyboard and state tests with `user-event`: Dialog focus trap and restore, Menu arrows/Esc, Tree
     keyboard, Combobox filter and select, Button pending, Toast announce.
   - `lib/theme`: persistence, system fallback, matchMedia change.
   - Contrast test that parses `tokens.css`: ≥4.5:1 for text pairs and ≥3:1 for UI boundaries and focus ring, both themes.
   - `/dev/ui` renders under test.
   - `src/test-setup.ts` stubs `ResizeObserver`, `hasPointerCapture`, `scrollIntoView` (Radix Select/Menu in jsdom).
10. **Docs.** CLAUDE.md: Gotchas for the jsdom stubs, the token rule (`@theme inline`, no default palette), `/dev/ui`, the
    theme storage key and the CSP-hash note. docs-keeper adds `docs/modules/ui.md` and `docs/modules/theme.md`.
