## Scope
1. **Editor:** CodeMirror 6 with Markdown language support only (R-1 lists `codemirror` 6.0.2; prefer the minimal set:
   `@codemirror/view`, `state`, `lang-markdown`, `commands` and what's strictly needed, vs the `codemirror` meta package: measure
   and justify, D-034). Lazy-loaded so it only downloads in edit mode. Themed with our tokens (light/dark), accessible label,
   Tab doesn't trap focus (Esc-then-Tab or CodeMirror's `indentWithTab` off, document the choice).
2. **Edit / Preview tabs** (Preview = `MarkdownView`). Own **Save** button with pending state; PUT with `If-Match: "c-N"`; 1 MiB
   client check with a clear message; identical body = no new version (fine, just toast "No changes").
3. **Independence from the Basics form:** saving the description doesn't submit or reset Basics, and vice versa. Its own unsaved
   state counts for the W-08 unsaved guard. **Check against the real backend whether a content save bumps the item `version`**; if
   it does, update the form's base version like W-09 (W-08 note), without touching the Basics draft. Record what you found.
4. **Conflict (UI_SPEC §9) for content:** 412 keeps the Markdown draft, banner, Copy my draft (Markdown text), Reload latest with
   confirmation. Network/5xx: inline error + Retry, draft kept.
5. **History drawer** (`Drawer`): versions newest first with relative time and size; selecting one loads and previews it read-only
   (`MarkdownView`), **Restore this version** with confirmation, sending the **current** content ETag; success updates the editor/view
   and the list. 404 on a pruned version → message + refresh list. Disabled while the editor has unsaved changes (or ask first).
6. **View mode:** History button next to the description (W-07 left it out).
7. **Dev mocks:** `devContent.ts`: per-item content with versions and retention, restore, 412 on stale ETag.
8. **Tests** (test-writer; you run and review): AT-08 web (sanitizing already covered: add a Preview case), save/no-op/413, 412 keeps
   draft, independence from Basics, history list/preview/restore with current ETag, pruned 404, unsaved guard integration.
9. **Docs:** CLAUDE.md (editor lazy-load, content version rules), docs-keeper updates `docs/modules/items.md`.
