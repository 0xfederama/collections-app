## Checklist
**Scope fence (AT-19), both repos:** no auth/users/memberships, TMDB/provider lookups, public-API features (keys, rate limits), AI/LLM,
WebSockets/real-time/CRDT/offline, ORM, Redis, queues; no tables, endpoints, routes, deps or dead scaffolding for them
(grep code, `go.mod`, `package.json`, migrations, spec). Allowed: the documented seams (DATA_MODEL §9, ARCHITECTURE §7).

**Backend**
- Uploads: magic-byte sniffing (JPEG/PNG/WebP only, SVG rejected), 40 MP check before decode, 10 MiB `MaxBytesReader`, generated storage
  keys, no path traversal in `FileStore` (`os.Root`), original filename display-only.
- Served files: `Content-Type` from DB, `nosniff`, `Content-Disposition: inline`, CSP `default-src 'none'`, caching headers.
- URLs (official site, image URL, IMDb) http/https only; `javascript:`/`data:` rejected.
- Errors: no SQL, paths, stack traces or driver messages in any problem response or 500 body (incl. panics); logs carry no secrets or
  request bodies.
- Request guard: body limits on every JSON route, unknown fields rejected, If-Match rules (AT-10) still complete for every mutating op.
- SQL: every query filters by `workspace_id`; no string-built SQL; LIKE escaping in list filter and search.
- Exposure: dev/test/prod compose publish only on `127.0.0.1` unless the documented opt-in (AT-18; `make check-compose`,
  `deploy/server/check.sh`); containers non-root; distroless runtime.
- Secrets: none in either repo or history-visible files (`.env*` gitignored, examples blank); backup manifests contain no secrets.
- `make audit` (govulncheck): clean, or each finding triaged (reachable? fix version?).

**Web**
- Markdown: no raw HTML rendering, link/image URL sanitizing (`javascript:` etc.), external links `rel="noopener noreferrer"`.
- CSP of the production image (D-072): no `unsafe-inline`/`unsafe-eval` relaxations beyond what's documented and justified; check it in
  the browser on `./deploy/test` or a throwaway `./deploy/prod` (`PROD_PROJECT=collections-app-q05`), 0 violations.
- No `fetch`/XHR outside `lib/api`; no `dangerouslySetInnerHTML` (or each use justified); no secrets or env values in the bundle
  (inspect `dist/`); `npm run audit` clean or triaged.
