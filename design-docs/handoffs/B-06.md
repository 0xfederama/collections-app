## Scope
- Service `internal/tree` (no HTTP), queries in `db/queries/folders.sql` and `lists.sql` (every query filters by `workspace_id`; sqlc
  regenerated and committed). Handlers in `folders.go`, `lists.go`, `tree.go` (methods moved out of `unimplemented.go`).
- **Create**: appended last among active siblings (`sort_order = max+1` under a lock on the parent, or the root scope for root items);
  missing or trashed parent → 409 `destination_unavailable`; 201 + `Location` + `ETag`.
- **Update** (PATCH): folder `name`; list `name`, `description`, `display_mode`, `sort_mode`. If-Match `"f-N"` / `"l-N"` → 412 with
  `current_version` on mismatch; `version + 1`, `updated_at`. Field rules → 422 (name 1–200 trimmed, enums, description length per DATA_MODEL).
- **Move**: destination must be active (else 409 `destination_unavailable`); folders: cycle check (into itself or any descendant → 409
  `cycle_detected`, DB unchanged; recursive CTE over active folders, with the moved row locked); appended last at the destination;
  bumps the moved resource's `version`.
- **Reorder** (DATA_MODEL §7): lock the parent (or root scope), load active sibling IDs, require set equality (duplicate, missing,
  foreign or trashed ID → 409 `order_stale`), rewrite `sort_order = index`, no version bumps, 204.
- **Tree**: all active folders and lists, flat, ordered by `sort_order, id`. `List.item_count` = active items.
- **Concurrency**: pick one locking scheme for the root scope (no parent row to lock: e.g. lock the workspace row, or an advisory lock
  keyed by workspace) and use it for create/move/reorder at the root. Record it in DECISIONS.md.
- Not-found and trashed resources → 404 `not_found`.

## Tests (integration, testcontainers)
