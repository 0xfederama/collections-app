## Scope
1. **Hooks** in `src/features/items/api.ts`: item GET (with `path`), content GET, item DELETE and move (`If-Match` from `version`,
   no retry on 412), exported query keys; invalidate the list items query (W-06 keys) and the tree (item counts) on delete/move.
2. **Per-kind configs** `src/features/items/kinds/*.ts`, one per kind (generic, movie, tv_show, motorcycle, car, camera), mirroring
   DATA_MODEL §2.1: key, label, input type, unit, enum options with labels, formatting. Typed against the generated per-kind
   schemas so a field rename breaks the build. A test asserts every generated metadata key has a config entry and vice versa.
3. **View mode** top to bottom per UI_SPEC §4: hero image or fallback tile (click → lightbox Dialog with the original), title + kind
   badge + status chip + price, the three links, summary, kind section (definition grid with units, hidden when empty; movie/TV:
   IMDb link, streaming platforms with country label and a warning when the country differs from settings; TV years
   `2019–2023` / `2019–present`), description, footer with created/updated and Move, Delete. An "Edit" button is a disabled
   placeholder (W-08). No "History" button yet (W-10).
4. **External links (AT-13):** exactly three controls in order: Google, Reddit, Official site. Query rules from PRODUCT §9 (movie
   adds release year if set + `film`, TV adds `TV series`, Reddit adds ` site:reddit.com`), built with `URLSearchParams`/
   `encodeURIComponent`; official disabled with "No official site" when absent, never a search; `target="_blank"` +
   `rel="noopener noreferrer"`; only `http(s)` official URLs rendered as links. A pure `buildExternalLinks(item)` with table tests
   (titles with `&`, `#`, quotes, unicode).
5. **Markdown rendering:** a `MarkdownView` component with `react-markdown` + `remark-gfm` (R-1 versions; justify, D-034): raw HTML
   off, links and images through a URL sanitizer (only `http`, `https`, `mailto`; relative allowed), links open with
   `rel="noopener noreferrer"`. W-10 reuses it for Preview. Tests for `javascript:` / `data:` links and raw `<script>`.
6. **Move / Delete:** Move dialog picks a target list (Combobox over the tree's lists, current list disabled), POST move with
   `If-Match`, then navigate to the item in its new list. Delete = AlertDialog ("goes to Trash"), then back to the list. 412 / 404 /
   409 / network per UI_SPEC §9 with toasts.
7. **W-06 follow-up, panel close:** closing the detail panel at ≥ 1280 must keep the list's `?q=` and `?sort=` (and scroll).
8. **W-06 follow-up, bundle size:** the JS bundle is ~675 kB. Lazy-load route components in `router.tsx` (ListRoute, ItemRoute,
   SearchRoute, TrashRoute, SettingsRoute) with skeleton fallbacks; report before/after sizes in the PR. Don't change SearchRoute's
   contents.
9. **States:** skeleton matching the layout, 404 (item gone or trashed) → not-found message with a link back to the list, error +
   Retry.
10. **Tests** (test-writer; you run and review): AT-13 table, each kind's section (incl. hidden when empty, units, TV years),
    streaming country warning, Markdown sanitizing, move/delete flows and 412, panel vs full page, panel close keeps query.
11. **Docs:** CLAUDE.md (remove the stale "Seams (W-05 ∥ W-06)" bullet, add items/markdown notes); docs-keeper adds
    `docs/modules/items.md`.
